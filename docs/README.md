# Project Source

`K-TIRAE-project-brief.docx` is the project brief supplied for this repository. It is the reference for the academic scope, mandatory compliance checks, data model, risk-scoring assumptions, ethics requirements, and presentation expectations.

The brief is a planning source, not official KRA policy. The implementation must continue to use synthetic or anonymised data and must preserve human review safeguards.

The repeatable synthetic business scenarios, their rationale, and domain assumptions are documented in [test-scenarios.md](test-scenarios.md). Thresholds and matching rules must be validated against authoritative requirements before being treated as operational rules.

When the source brief changes, replace the tracked DOCX, commit the change, and note the affected requirement in the next weekly report. The two-hour GitHub workflow publishes the tracked document's SHA-256 hash in the README so source changes are visible.
