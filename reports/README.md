# Progress Reports

Weekly reports for the five-week K-TIRAE delivery timeline live in this folder.

- `week-01.md` is the completed weekly report currently on file. Add later weekly reports as their reporting periods close and evidence is reviewed.
- Dated `checkpoint-*.md` files preserve operational verification snapshots between weekly reports.
- Use `WEEKLY_REPORT_TEMPLATE.md` at the repository root for each new report.
- Reports should link to the relevant commit, tests, screenshots, and decisions.
